# Jamestomasino Beep

## How do I install these formulae?

`brew install jamestomasino/beep/<formula>`

Or `brew tap jamestomasino/beep` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "jamestomasino/beep"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
